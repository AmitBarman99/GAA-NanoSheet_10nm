# GAA-NanoSheet_10nm
This study presents the physics-based design and numerical simulation of a gate-all-around (GAA) nanosheet field-effect transistor (NS-FET) using the Synopsys Sentaurus TCAD platform, targeting sub-10-nm technology node applications. A three-dimensional device structure comprising vertically stacked silicon nanosheets was constructed, and a calibrated mesh strategy was employed to resolve critical electrostatic and quantum-mechanical effects. The simulation framework incorporates advanced physical models, including drift–diffusion transport, density-gradient quantum corrections, high-field mobility degradation, carrier scattering mechanisms, and interface trap dynamics.

Analyzed the Transfer Characteristics \& Output Characteristics by changing gate materials (PolySi, Al, Mo, Ti), gate oxide ( $SiO_2, HfO_2$) and voltages.
